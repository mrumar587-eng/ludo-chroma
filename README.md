# Ludo Chroma

A responsive, installable offline-first Ludo Chroma web application built with React, TypeScript, and Tailwind CSS.

## Privacy

This game works offline once loaded and stores only your preferences, current saved game, match statistics, and unlocked achievements locally on your device (`localStorage` and browser cache). It contains no analytics, tracking scripts, cookies, or user accounts, and sends no data to any server. When online, loading the Plus Jakarta Sans font contacts Google's font servers (`fonts.googleapis.com` and `fonts.gstatic.com`), which are then cached locally for offline play.
